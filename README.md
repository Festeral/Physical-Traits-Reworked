# Physical Traits Reworked

Versioned manual downloads for the CK3 mod.

## v1.2.1 manual rollback

[Download the v1.2.1 manual-install ZIP](https://github.com/Festeral/Physical-Traits-Reworked/releases/download/v1.2.1/Physical_Traits_Reworked_v1.2.1_Manual.zip)

This frozen archive is available for players reporting portrait issues in existing saves after v1.3.0. Supported CK3 version: **1.20.***.

1. Close CK3 and its launcher. Extract the included `physical_traits_reworked_1_2_1` folder and `.mod` file into `Documents\Paradox Interactive\Crusader Kings III\mod`.
2. In your playset, disable Workshop PTR and enable **Physical Traits Reworked v1.2.1 (Local)**. If using EPE, keep EPE before PTR.
3. Restart CK3 and test a backup of a save made before the update.

This local copy does not receive Workshop updates. Recovery of affected saves has not been verified. The ZIP includes full installation instructions.
